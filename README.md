**SOLMAR** — an original open-world crime game in a sunny coastal city. Drive for hire as Marco Vale, run five story jobs for the fixer Rico, steal cars, outrun the Solmar police, and build your cash from $250 to king of the coast. A complete 3D open world (three.js, vendored, no network requests): an 8×8-block city with downtown, marina, old town, beachfront and a park, traffic and pedestrians, a 0–5 star wanted system with police chases, punch and pistol combat, a HUD with minimap, and a save that persists in the browser. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```

Or open `game/index.html` directly — the game is static files under `game/` and plays offline with zero network requests.

**Controls:** WASD move · Shift run · E enter/exit car & pick up · F punch · G pistol · Space handbrake · drag mouse: camera · wheel: zoom · Esc pause.

**Missions:** First Fare ($150) · Hot Wheels ($250) · Lose the Heat ($200) · The Package ($400) · Solmar Sprint ($600) — then free roam with random taxi fares.
